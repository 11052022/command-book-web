# 📖 Command Book 用户手册（v2 在线版）

> 写给完全没接触过命令行的新手。一步一步跟着做，就能用起来。

## 1. 这是什么？

一本「会帮你拼命令」的速查电子书。想不起来命令怎么用？输入大白话就能搜到，并给出中文说明、语法、参数示例，一键复制。

三大模块：🐧 Linux（服务器常用命令）、🔴 Redis（缓存/消息队列常用命令）、🔀 Git（代码版本管理命令）。

## 2. 怎么运行

### 方式 A：开发模式（推荐调试用）

```bash
npm install     # 第一次用才需要
npm run dev     # 启动后浏览器打开 http://localhost:5173
```

改代码保存后页面自动刷新。

### 方式 B：构建后部署

```bash
npm run build   # 产出 dist/ 静态文件
```

把 `dist/` 文件夹上传到任意静态托管平台（Gitee Pages、GitHub Pages、Nginx 等）即可对外访问。

## 4. 搜索技巧

- **中文描述**：输入「删除 日志」——空格分隔多个词，命中条件越多越靠前；
- **命令名直搜**：输入 `tar`、`grep`，精确匹配排最前；
- **只看某种类型**：搜索框下方点「命令」或「配方」；或在输入框敲 `#recipe`（只看配方）、`#命令`（只看命令）；
- **看不懂为什么搜到它**：卡片上被高亮的标签就是原因。

快捷键：`/` 聚焦搜索，`j`/`k` 或 `↑`/`↓` 在结果间移动，`Enter` 展开卡片，`Esc` 收起。

## 6. 常见问题

**Q：改了数据（JSON）页面没变化？**
A：开发模式会自动刷新；构建部署需重新 `npm run build`。改完数据请先跑 `npm run check` 校验字段，避免因缺字段导致页面打不开。

**Q：`npm run check` 报红字「缺字段」是什么意思？**
A：你加入的命令/配方少了必填字段（如 `name`、`description`、`examples`）。按报错提示补全后重新运行即可。

**Q：页面全黑 / 空白？**
A：按 `F12` → 控制台（Console）看红色报错，截图发给维护者。v1 曾因数据缺 `_type` 整页黑屏，本版已通过校验脚本从源头拦住。

**Q：部署后刷新 404？**
A：本版使用 hash 路由（URL 形如 `/ #/linux`），任意静态托管都不会 404，无需额外配置。

**Q：收藏/主题被清空？**
A：它们存在浏览器 `localStorage`，换浏览器、隐私模式或清理缓存后会重置，属正常现象。
